# نظام حجز قاعات كلية اللغة العربية

## 🎯 نظرة عامة على المشروع

نظام حجز قاعات شامل ومتطور لإدارة حجوزات قاعة المناقشة وقاعة التدريب في كلية اللغة العربية. يوفر النظام واجهة عربية سهلة الاستخدام مع دعم التقويمين الهجري والميلادي، ونظام تقارير متقدم، وإدارة شاملة للحجوزات.

## ✨ الميزات الرئيسية

### 🗓️ إدارة التقويم
- **عرض شهر واحد** مع أسهم تنقل سهلة بين الأشهر
- **تقويم تفاعلي** يدعم التقويمين الهجري والميلادي
- **تحويل تلقائي** بين التاريخين الهجري والميلادي
- **مؤشرات بصرية للحجوزات** - أيقونات للقاعات مع عرض أول حجزين
- **عداد الحجوزات الإضافية** - عرض "+X" للحجوزات الإضافية
- **تصفية حسب القاعة** لعرض حجوزات قاعة محددة
- **نقر سريع** على التواريخ للحجز المباشر

### 🏛️ إدارة القاعات
- **قاعة المناقشة** - سعة 50 شخص
- **قاعة التدريب** - سعة 30 شخص
- **عرض حالة القاعات** في الوقت الفعلي (متاحة/مشغولة)
- **تحديث تلقائي** لحالة القاعات كل دقيقة

### 📋 نظام الحجز المتطور
- **نموذج حجز شامل** مع جميع البيانات
- **اختيار بالأيقونات** - واجهة تفاعلية بالأيقونات بدلاً من القوائم المنسدلة
- **حجز بدون قيود** - جميع الحقول اختيارية، لا توجد حقول إلزامية
- **الأقسام المدعومة**:
  - 🗣️ قسم اللغويات
  - 📖 قسم الأدب والبلاغة
  - 📡 قسم الإعلام
  - 🎓 قسم التربية
  - 📜 قسم التاريخ
  - 🌍 قسم اللغات والترجمة
  - 🏢 حجز من خارج الكلية
  - ⋯ أخرى
- **تحقق من التعارض** التلقائي للأوقات
- **تأكيد فوري** للحجوزات
- **عرض تفاصيل الحجز** مع إمكانية التعديل للمديرين

### 👤 نظام إدارة المديرين
- **دخول آمن** برقم سري (091986)
- **تعديل الحجوزات** الموجودة
- **إلغاء الحجوزات** مع تأكيد
- **حذف نهائي** للحجوزات
- **واجهة إدارية** مخصصة مع مؤشرات بصرية

### 📊 نظام التقارير المتقدم
- **تقارير أسبوعية** لعرض إحصائيات الحجز لكل أسبوع
- **تقارير شهرية** لعرض نشاط الحجز طوال العام
- **تقارير سنوية** لمقارنة السنوات المختلفة
- **رسوم بيانية تفاعلية** باستخدام Chart.js
- **إحصائيات مفصلة** لكل قسم
- **بطاقات إحصائية** تعرض:
  - إجمالي الحجوزات
  - القسم الأكثر نشاطاً
  - متوسط الحجوزات لكل فترة
  - القاعة الأكثر استخداماً

### 📝 سجل الحجوزات الشامل
- **عرض قائمة كاملة** بجميع الحجوزات (السابقة، الحالية، القادمة)
- **فلترة متقدمة** حسب:
  - الزمن (الكل، السابقة، اليوم، القادمة)
  - القاعة المحجوزة
  - القسم الحاجز
- **بحث نصي** في جميع حقول الحجز
- **ترقيم الصفحات** لعرض 20 حجز في كل صفحة
- **أزرار إجراءات سريعة** لكل حجز:
  - 👁️ عرض التفاصيل الكاملة
  - ✏️ تعديل الحجز (للمديرين)
  - 🗑️ حذف الحجز (للمديرين)
- **تحديث تلقائي** عند إضافة أو تعديل أو حذف حجز
- **عرض الحالة** بألوان مختلفة (سابق، اليوم، قادم)

### 🎨 تصميم متجاوب وحديث

- **الوضع الداكن** 🌓 - تبديل سهل بين الوضع الفاتح والداكن مع حفظ التفضيل
- **ألوان متدرجة** جذابة ومهدئة للعين

## 🗄️ هيكل قاعدة البيانات

### جدول الأقسام (departments)
- `id` - معرف القسم الفريد
- `name` - اسم القسم
- `type` - نوع القسم (department/external/other)
- `active` - هل القسم نشط

### جدول القاعات (rooms)
- `id` - معرف القاعة الفريد
- `name` - اسم القاعة
- `type` - نوع القاعة (discussion/training)
- `capacity` - سعة القاعة
- `active` - هل القاعة نشطة

### جدول الحجوزات (bookings)
- `id` - معرف الحجز الفريد
- `room_id` - معرف القاعة
- `department_id` - معرف القسم
- `title` - عنوان الحجز
- `date_gregorian` - التاريخ الميلادي
- `date_hijri` - التاريخ الهجري
- `start_time` - وقت البداية
- `end_time` - وقت النهاية
- `contact_person` - اسم المسؤول
- `contact_phone` - رقم الهاتف
- `notes` - ملاحظات إضافية
- `status` - حالة الحجز (confirmed/cancelled)
- `booking_date` - تاريخ إجراء الحجز

## 🚀 طريقة الاستخدام

### للمستخدمين العاديين
1. **عرض التقويم**: 
   - اطلع على شهر واحد مع الحجوزات الموجودة
   - استخدم الأسهم ◄ ► للتنقل بين الأشهر
   - التبديل للوضع الداكن 🌓 عند الحاجة
2. **حجز جديد**: 
   - انقر على الأيقونة لاختيار القاعة المطلوبة (💬 مناقشة أو 👨‍🏫 تدريب) - اختياري
   - انقر على أيقونة القسم المطلوب - اختياري
   - اختر التاريخ والوقت - اختياري
   - جميع الحقول اختيارية - يمكنك الحجز بدون ملء أي حقل!
3. **تأكيد الحجز**: انقر على "تأكيد الحجز" وستظهر رسالة نجاح
4. **البحث في السجل**: استخدم سجل الحجوزات للبحث عن حجز محدد
5. **تصفية الحجوزات**: استخدم الفلاتر لعرض حجوزات محددة حسب الوقت أو القاعة

### للمديرين
1. **دخول وضع المدير**: انقر على "إدارة النظام" وأدخل الرقم السري (091986)
2. **إدارة من التقويم**: انقر على أي حجز في التقويم للعرض والتعديل والإلغاء
3. **إدارة من السجل**: استخدم أزرار الإجراءات في سجل الحجوزات:
   - 👁️ عرض التفاصيل الكاملة
   - ✏️ تعديل الحجز
   - 🗑️ حذف الحجز
4. **البحث المتقدم**: ابحث عن حجوزات محددة في السجل
5. **عرض التقارير**: اطلع على الإحصائيات التفصيلية والرسوم البيانية
6. **تحديث السجل**: انقر على زر التحديث لإعادة تحميل البيانات

### استخدام التقارير
1. **اختر نوع التقرير**: أسبوعي، شهري، أو سنوي
2. **حدد الفترة**: اختر السنة والشهر حسب نوع التقرير
3. **عرض النتائج**: اطلع على الإحصائيات والرسوم البيانية
4. **تحليل البيانات**: استخدم البيانات لاتخاذ قرارات إدارية
