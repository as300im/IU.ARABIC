# نظام حجز قاعات كلية اللغة العربية

## 🎯 نظرة عامة على المشروع

نظام حجز قاعات شامل ومتطور لإدارة حجوزات قاعة المناقشة وقاعة التدريب في كلية اللغة العربية. يوفر النظام واجهة عربية سهلة الاستخدام مع دعم التقويمين الهجري والميلادي، ونظام تقارير متقدم، وإدارة شاملة للحجوزات.

## ✨ الميزات الرئيسية

### 🗓️ إدارة التقويم
- **عرض تقويم تفاعلي** يدعم التقويمين الهجري والميلادي
- **تحويل تلقائي** بين التاريخين الهجري والميلادي
- **عرض الحجوزات** باللون الأحمر على التقويم
- **تصفية حسب القاعة** لعرض حجوزات قاعة محددة
- **نقر سريع** على التواريخ للحجز المباشر

### 🏛️ إدارة القاعات
- **قاعة المناقشة** - سعة 50 شخص
- **قاعة التدريب** - سعة 30 شخص
- **عرض حالة القاعات** في الوقت الفعلي (متاحة/مشغولة)
- **تحديث تلقائي** لحالة القاعات كل دقيقة

### 📋 نظام الحجز المتطور
- **نموذج حجز شامل** مع جميع البيانات المطلوبة
- **قائمة منسدلة للأقسام** تشمل:
  - قسم اللغويات
  - قسم الأدب والبلاغة
  - قسم الإعلام
  - قسم التربية
  - قسم التاريخ
  - قسم اللغات والترجمة
  - حجز من خارج الكلية
  - أخرى
- **تحقق من التعارض** التلقائي للأوقات
- **تأكيد فوري** للحجوزات
- **عرض تفاصيل الحجز** مع إمكانية التعديل للمديرين

### 👤 نظام إدارة المديرين
- **دخول آمن** برقم سري (091986)
- **تعديل الحجوزات** الموجودة
- **إلغاء الحجوزات** مع تأكيد
- **حذف نهائي** للحجوزات
- **واجهة إدارية** مخصصة مع مؤشرات بصرية

### 📊 نظام التقارير المتقدم
- **تقارير أسبوعية** لعرض إحصائيات الحجز لكل أسبوع
- **تقارير شهرية** لعرض نشاط الحجز طوال العام
- **تقارير سنوية** لمقارنة السنوات المختلفة
- **رسوم بيانية تفاعلية** باستخدام Chart.js
- **إحصائيات مفصلة** لكل قسم
- **بطاقات إحصائية** تعرض:
  - إجمالي الحجوزات
  - القسم الأكثر نشاطاً
  - متوسط الحجوزات لكل فترة
  - القاعة الأكثر استخداماً

### 🎨 تصميم متجاوب وحديث
- **تصميم عربي** كامل مع دعم الاتجاه من اليمين لليسار
- **ألوان متدرجة** جذابة ومهدئة للعين
- **رسوم متحركة** سلسة للانتقالات
- **متوافق مع الهواتف** والأجهزة اللوحية
- **خط Cairo** الأنيق للنصوص العربية

## 🗄️ هيكل قاعدة البيانات

### جدول الأقسام (departments)
- `id` - معرف القسم الفريد
- `name` - اسم القسم
- `type` - نوع القسم (department/external/other)
- `active` - هل القسم نشط

### جدول القاعات (rooms)
- `id` - معرف القاعة الفريد
- `name` - اسم القاعة
- `type` - نوع القاعة (discussion/training)
- `capacity` - سعة القاعة
- `active` - هل القاعة نشطة

### جدول الحجوزات (bookings)
- `id` - معرف الحجز الفريد
- `room_id` - معرف القاعة
- `department_id` - معرف القسم
- `title` - عنوان الحجز
- `date_gregorian` - التاريخ الميلادي
- `date_hijri` - التاريخ الهجري
- `start_time` - وقت البداية
- `end_time` - وقت النهاية
- `contact_person` - اسم المسؤول
- `contact_phone` - رقم الهاتف
- `notes` - ملاحظات إضافية
- `status` - حالة الحجز (confirmed/cancelled)
- `booking_date` - تاريخ إجراء الحجز

## 🚀 طريقة الاستخدام

### للمستخدمين العاديين
1. **عرض التقويم**: اطلع على الحجوزات الموجودة والأيام المتاحة
2. **حجز جديد**: املأ النموذج بالبيانات المطلوبة
3. **اختيار القسم**: حدد قسمك من القائمة المنسدلة
4. **اختيار التاريخ والوقت**: حدد التاريخ والوقت المناسب
5. **تأكيد الحجز**: أكد الحجز وستظهر رسالة نجاح

### للمديرين
1. **دخول وضع المدير**: انقر على "إدارة النظام" وأدخل الرقم السري
2. **تعديل الحجوزات**: انقر على أي حجز لعرض التفاصيل والتعديل
3. **إلغاء الحجوزات**: يمكن إلغاء أي حجز مع الاحتفاظ بالسجل
4. **عرض التقارير**: اطلع على الإحصائيات التفصيلية
5. **إدارة البيانات**: أضف قاعات وأقسام جديدة عند الحاجة

### استخدام التقارير
1. **اختر نوع التقرير**: أسبوعي، شهري، أو سنوي
2. **حدد الفترة**: اختر السنة والشهر حسب نوع التقرير
3. **عرض النتائج**: اطلع على الإحصائيات والرسوم البيانية
4. **تحليل البيانات**: استخدم البيانات لاتخاذ قرارات إدارية
